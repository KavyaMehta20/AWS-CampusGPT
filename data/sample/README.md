# Sample University Data (Testing Only)

This folder contains fictional, mock university documents and reference databases used to verify that CampusGPT's ingestion, retrieval, and MCP tools function out-of-the-box before real university documents are loaded.

- `handbook.md`: Fictional policies, advising rules, and graduation criteria.
- `courses.json`: Mock course catalog entries for MCP tool queries.
- `calendar.json`: Mock academic calendar events for MCP tool lookups.

> **IMPORTANT:** All content in this directory is labeled as sample data and is not related to RIT or any real institution.

# AWS Deployment Module

Contains serverless deployment definitions for AWS Lambda, API Gateway, S3, and AWS Secrets Manager using AWS SAM (Serverless Application Model).

- `template.yaml`: Complete AWS SAM CloudFormation template.
- `lambda_handler.py`: Mangum ASGI adapter for FastAPI with Secrets Manager cold-start fetching.
- `DEPLOY_GUIDE.md`: 6-step walkthrough for workshop presenters.

# Frontend Application

Plain HTML, CSS, and modern JavaScript interface (no framework or build step needed).

## Visual Identity:
- Navy `#101B2D`
- Accent Orange `#E58A32`
- Light Neutral Background `#F4F6F8`

## Key Teaching Component:
- **"How CampusGPT answered" Collapsible Panel:**
  Displays the step-by-step pipeline execution for students:
  - Guardrail checks with green/red status tags.
  - Retrieved vector candidate chunks before reranking.
  - Reranked chunk ordering after lexical/cross-encoder reranking.
  - MCP tool calls and latency measurements.
